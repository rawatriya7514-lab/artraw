## 🛠️ Getting Started

### 1. Prerequisites
- Node.js 18+ (tested on Node.js 20 LTS)
- npm or pnpm

### 2. Installation
```bash
npm install
```

### 3. Development Server
```bash
npm run dev
```

### 4. Production Build
```bash
npm run build
```

The production output is bundled into `dist/`.

### 5. Automated Tests & Audits
```bash
node audit-test.mjs
node flow2-test.mjs
```

---

## 📦 Deployment

To deploy to GitHub Pages:
```bash
npm run deploy
```
